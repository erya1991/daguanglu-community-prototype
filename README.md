# 大光路物业运营平台需求与演示原型

仓库建议名称：`daguanglu-community-prototype`。

本项目保存商城之外由 lee 统筹的产品需求、演示原型、验收与研发交接资料。商城继续由原项目推进；居民共享与邻里互助由同事设计。本项目保留整个建设方案的功能对应关系，方便后续整合。

## 当前状态

- 当前步骤：项目初始化，项目级文档与范围台账已准备。
- 业务阶段：Stage00～Stage05 均未启动。
- Git：初始化包不包含 `.git`。在实际本地路径完成初始化、首次提交和远程推送后，以命令结果更新本节。
- 原型：当前没有业务页面、前端依赖或启动服务；技术栈在 Stage00 启动时结合团队规范确定。
- 生产进度：以研发和原商城项目实际记录为准，本仓库尚未核定。

本轮用户决定为“先创建仓库并准备项目级文档，再分 Stage 执行”。上轮六阶段分组与产品交接日期保留为讨论建议，不视为全部业务规则或开发交期已确认。

## 第一次使用

1. 按 [仓库和本地准备说明](docs/REPOSITORY_SETUP.md) 将文件放到独立目录，创建空的远程仓库并完成首次提交推送。
2. 在 Codex 中打开该目录，先读取 [AGENTS.md](AGENTS.md)，完成项目文档初始化核对。
3. 查看 [阶段计划](docs/STAGES.md)，由用户启动一个 Stage，再创建对应阶段文档并进入需求流程。

建议本地位置：`D:\git\daguanglu-community-prototype`。此目录与商城生产开发目录分开。初始化阶段只需要 Git 和文本编辑环境，不需要安装前端框架或数据库。
