## 资料优先关系

1. 用户最新明确决定及可核验的后续业务确认，优先于历史描述。本轮只确定先初始化，未把六Stage建议或所有业务规则一次冻结。
2. S0为本轮建设方案主依据；S0在会话中提供，本目录未伪造一份全文文件。SOURCE_COVERAGE只保留逐项映射和摘要，正式原稿补充后应记录来源与版本。
3. 商城内部以较新的S3／S4 P0资料和原项目实际记录为依据，继续独立开发。新原型项目不复制商城内核，也不因S1／S2较旧口径回退商城。
4. S1／S2用于旧编号和范围差异追溯，S5～S7用于课题及历史架构边界。历史增强需求进入问题台账评估，不自动纳入本月。
