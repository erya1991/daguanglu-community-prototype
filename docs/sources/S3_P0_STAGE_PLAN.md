# 大光路智慧社区 P0 商城闭环｜产品开发总清单与六阶段计划

> 用途：作为 P0 商城闭环产品、研发、测试统一范围基线。  
> 范围：仅包含本次商城完整闭环，不包含社区服务、物业、停车、居民共享、活动、团购、Project、多社区等其他能力。  
> 技术底座：LiLiShop。成熟商城内核优先复用，仅对大光路社区差异进行改造或新增。

---

## 1. 复用类型说明

| 类型 | 含义 |
|---|---|
| 直接复用 | LiLiShop 已具备完整业务能力或页面，主要完成配置、接口接入、权限与回归，不重新建设 |
| 复用改造 | 保留 LiLiShop 原业务对象、流程或现有前端页面，在其基础上补充大光路字段、规则、状态、页面或接口适配 |
| 重新开发 | LiLiShop 缺少对应产品界面或完整业务能力，需要新增页面、业务对象或完整业务流程 |
| 无独立前端 | 仅为后端/渠道/业务支撑能力，不形成独立用户菜单或页面 |

> 判断原则：同一个功能前端和后端可采用不同实现类型，例如“住户商品详情”可为前端重新开发、后端复用改造。

### 验收退出条件

- 住户真实微信登录成功，同一微信用户重复登录仍为同一 Member；
- 手机号绑定/更新规则验证通过；
- 商户负责人和工作人员可正常登录；
- 未入驻负责人具备提交本人入驻申请的身份；
- 登录后 Store 数据范围不能由前端参数扩大；
- 住户与商户两个小程序 AppID、会话和身份完全隔离；
- 微信开发者工具/真机完成最小登录验证。
