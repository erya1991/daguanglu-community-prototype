# 大光路智慧社区数字化运营平台 V1.0 一期开发清单总表

> 版本：范围重排版（2026-08-26）  
> 用途：作为V1.0研发任务拆解、排期、产品详细设计和测试验收的范围基线。  
> 一期截止：**2026-11-30**  
> 一期业务优先级：**P1 商城闭环 → P2 社区服务闭环 → P3 物业缴费与房屋绑定 → P4 居民共享与邻里互助 → P5 停车缴费**。  
> 配套能力：平台基础、商户准入、微信支付/退款/分账、最小积分、消息与数据初始化按上述业务依赖穿插建设。  
> 产品端：管理后台 Web、住户小程序、商户小程序。  
> 下一期：社区活动、社区团购、报修投诉/物业工单、巡检、运营作业小程序、空间资源运营、课题创新点等。

## 1. 优先级与复用标识

### 1.1 业务优先级

| 标识 | 说明 |
|---|---|
| P1 | 商城闭环，一期最高优先级 |
| P2 | 社区服务闭环 |
| P3 | 物业缴费与房屋绑定 |
| P4 | 居民共享与邻里互助 |
| P5 | 停车缴费 |
| SUPPORT | 为P1-P5提供支撑，不单独形成业务优先级 |

### 1.2 功能优先级

| 标识 | 说明 |
|---|---|
| S0 | 对应业务闭环上线必需，不完成则该业务不得视为完成 |
| S1 | 实际运营需要，原则上V1.0完成 |
| S2 | 体验/运营增强，可转下一期且不阻塞闭环 |

### 1.3 RuoYi复用标识

| 标识 | 说明 |
|---|---|
| A | 基本可直接复用，仅配置/本地化/页面适配 |
| B | 核心模型或能力可复用，需要增加社区字段、商户维度或规则 |
| C | 独立业务模型，但复用Pay、Member、File、System等公共能力 |
| D | 智慧社区新增能力，需要设计开发 |

## 3. 一期五条业务闭环验收口径

1. **P1 商城：** 商户入驻审核 → 商品发布审核 → 居民下单支付 → 商户履约 → 分账 → 退款/回退可验证。
2. **P2 社区服务：** 服务发布审核 → 居民预约支付 → 商户/人员接单 → 到场/开始/完成 → 分账/退款。
3. **P3 物业缴费与房屋绑定：** 居民绑定房屋 → 查询物业账单 → 微信缴费（可叠加最小积分抵扣） → 账单核销 → 缴费记录。
4. **P4 居民共享与邻里互助：** 社区身份校验 → 发布/审核 → 社区内展示 → 意向/认领/接单 → 线下交付或互助完成 → 确认/评价；**不以个人在线收款为一期条件**。
5. **P5 停车缴费：** 居民关联车辆 → 查询停车费账单 → 微信缴费 → 账单核销 → 缴费记录；**不建设停车场设备平台**。

- 停车场设备、闸机、车位实时占用、车牌识别平台；
