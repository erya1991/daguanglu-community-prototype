# 待确认问题与业务决策台账

> 版本：V0.3｜2026-11-05｜27个稳定问题编号保留；仅据完整Stage01 V0.3输入记录相关已确认子项及残项，部分确认不等于整项关闭。Stage00范围决定及实际验收结论保持原记录。

## 使用方法

本台账用于与街道、社区、物业、运营、研发及厂商确认边界。问题内容和建议日期沿用上一轮讨论稿，不是已经约定的会议或对外承诺；本轮仅首次导入Stage01文档并最小同步已有决定，未发出消息或联系相关人员。输入包记录的原业务答复日期未提供，本地导入日期不代替原答复日期。

确认时记录具体选择、适用范围、规则参数、生效版本及实际依据。临时演示假设不能作为正式结论；没有接口资料不能据此承诺真实接入。一个问题可分项回答，保留未答部分并标为“部分确认”。新问题从Q28继续，不修改旧编号。

状态建议：待确认／确认中／部分确认／已确认／已撤回。只有记录实际结论和确认依据后才能标记“已确认”；撤回须记录由谁决定及影响。未答问题只阻塞依赖该结论的工作，独立部分照常推进。
